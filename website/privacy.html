Privacy

Histq has no account, no analytics and no telemetry. It talks to the network only in the cases below.

No account, no analytics

  • Histq has no account, and no analytics, telemetry or crash reporting SDK.
  • Its network use is listed below. The terminal drawer runs your own shell; what you run in it is up to you.

What the app sends over the network

  • Git. Fetch, pull, push and clone talk to your repository's remotes, as the git command would. Automatic fetch is off by default.
  • GitHub. Only after you add a token to a profile: requests go to api.github.com, or https://<host>/api/v3 for GitHub Enterprise. The token is sent only to that host.
  • Avatars. Generated on your Mac by default. Real avatars (opt-in, Settings › Appearance) send the SHA-256 hash of each author's email to gravatar.com, and GitHub user ids or logins to avatars.githubusercontent.com, with no token or cookies.
  • AI. Only when you click an AI button (or Test connection or Load models), and only to the provider you chose. Diffs are cut to about 24 KB.
  • Updates. Sparkle reads the update feed (appcast.xml) from raw.githubusercontent.com and downloads updates from GitHub Releases.
  • Unknown SSH hosts. ssh-keyscan reads the host's keys so you can compare the fingerprint before you trust it.

What stays on your Mac

  • GitHub tokens and AI keys are stored in the macOS Keychain.
  • Profiles, the session, undo journals and the avatar cache are in ~/Library/Application Support/Histq.
  • Settings, including your recent repositories, are in the app's preferences.
  • A host key you trust is added to ~/.ssh/known_hosts. Profiles are applied per git process, not written to your git config.

This website

  • Hosted on GitHub Pages, which may log requests and IP addresses.
  • No analytics and no cookies. Your theme choice is kept in local storage.
  • The version in the header is read from the GitHub API (api.github.com), which sees your IP address like any website you visit.
  • The Geist font is loaded from Google Fonts.

Questions

Histq is open source, so every claim here can be checked in the code. Questions? Open an issue on GitHub.
